# I4A 관리자 페이지

사용자 앱의 시간 제한을 밖에서 관리하는 웹페이지예요. Cloudflare Workers(무료)에 올려서 씁니다.

- 하루 허용 시간을 바꾸면 바로 저장되고, 사용자 앱에는 **20초 안에** 반영돼요. 앱을 다시 열 때는 즉시 반영돼요.
- **사용자 변경 막기**를 켜면, 앱의 시간 제한 메뉴를 사용자가 만질 수 없어요. 인터넷이 끊겨도 마지막 설정이 유지돼요.
- 오늘 사용 시간과, 사용자 기기에 **인스타그램 앱이 설치되어 있는지** 볼 수 있어요.

## 배포 (처음 한 번)

준비물: [Cloudflare 계정](https://dash.cloudflare.com/sign-up)(무료), Mac에 Node.js(`brew install node`).

1. 이 폴더로 이동해요.

   ```bash
   cd ~/Documents/works/I4A/admin
   ```

2. Cloudflare에 로그인해요. 브라우저가 열리면 허용을 눌러요.

   ```bash
   npx wrangler login
   ```

3. 관리자 비밀번호를 정해요. 명령을 실행하면 비밀번호를 입력하라고 나와요. 사용자가 짐작할 수 없는 값으로 정하세요.

   ```bash
   npx wrangler secret put ADMIN_TOKEN
   ```

4. 배포해요.

   ```bash
   npx wrangler deploy
   ```

   끝나면 `https://i4a-admin.<내계정>.workers.dev` 같은 주소가 나와요. 이 주소가 **관리자 페이지**예요.

5. 앱에 서버 주소를 넣어요. `I4A/Config/Local.xcconfig`(없으면 `Local.xcconfig.example`을 복사해서 만들어요)에 4번 주소를 **`https://` 없이** 적고, Xcode에서 사용자 아이폰에 다시 설치해요. 이 파일에서는 `//`가 주석이라 `https://`를 쓰면 안 돼요.

   ```
   I4A_ADMIN_HOST = i4a-admin.<내계정>.workers.dev
   ```

## 사용

관리자 페이지 주소를 열고 3번의 비밀번호를 입력하면 돼요. 비밀번호는 그 브라우저에 기억돼요.

| 항목 | 설명 |
| --- | --- |
| 오늘 사용 | 사용자가 오늘 쓴 시간 / 허용 시간 |
| 인스타그램 앱 | 사용자 기기에 원래 인스타그램 앱이 깔려 있는지 |
| 릴스 숨기기 잠금 | 켜면 앱에서 릴스가 항상 숨겨지고, 사용자가 끌 수 없어요 |
| 시간 제한 잠금 | 켜면 앱의 시간 제한 메뉴가 잠겨요 |
| DM 릴스 허용 계정 | 이 계정과의 1:1 DM에서 받은 릴스는 탭할 때마다 한 편씩 볼 수 있어요(기본: esleoseo, seoleims). 단체 DM, 다음 릴스로 넘기기는 계속 막혀요 |
| 시간 제한 사용 | 끄면 제한 없이 쓸 수 있어요 |
| 하루 허용 시간 | 프리셋을 누르거나 ± 버튼, 숫자 입력(1~1440분) |

## 참고

- 사용자는 한 명이라고 가정해요. 계정이나 멤버 관리는 없어요.
- 앱이 읽는 설정(`/api/policy`)은 비밀번호 없이 열려 있지만, 바꾸는 것(`PUT /api/policy`)은 관리자 비밀번호가 있어야 해요.
- 사용 시간과 설치 여부는 앱이 켜져 있을 때 20초마다 보고돼요. 앱이 꺼져 있을 때는 iOS가 가끔 실행해 주는 백그라운드 확인(보통 몇 시간 간격) 때 보고돼요. "앱 마지막 연결" 시각을 보면 얼마나 최신인지 알 수 있어요.
- 비밀번호를 바꾸려면 3번을 다시 실행하면 돼요.
